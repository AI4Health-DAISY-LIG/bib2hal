Guide

Get your publication list as a .bib file

bib2hal reads BibTeX, the format every reference manager can export. Use the tool where your list is the most complete — for many researchers, that is their Google Scholar profile.

You only need your own publications. If your library also contains papers by others, export just the folder or collection with your work, or select your papers before exporting. bib2hal will in any case flag references where it cannot find you among the authors.

From your Google Scholar profile

  1. Open scholar.google.com and go to My profile.
  2. Scroll to the bottom of your list and click Show more until all your publications are displayed.
  3. Tick the checkbox at the top of the list (next to "Title") to select every article shown.
  4. Click Export and choose BibTeX.
  5. Depending on your browser, a file is downloaded, or the BibTeX text opens in a new tab: in that case save the page (Ctrl+S / ⌘+S) as scholar.bib.

Google Scholar exports are often incomplete (no DOI, approximate document types). That is expected: bib2hal completes them from Crossref and asks you about the doubtful ones.

From Zotero

  1. In the left pane, select the collection that contains your publications (or My Library).
  2. Right-click the collection → Export Collection… — or, for the whole library, menu File → Export Library…. To export only some items, select them, right-click → Export Items….
  3. Format: BibTeX. You can leave "Export Notes" and "Export Files" unticked.
  4. Click OK and save the file, e.g. zotero.bib.

If you use the Better BibTeX plug-in, its format works too.

From Mendeley Reference Manager

  1. Open the collection with your publications and select them (Ctrl+A / ⌘+A selects all).
  2. Choose Export in the panel that appears for the selection.
  3. Select BibTeX (.bib) as the format and save the file.

With the older Mendeley Desktop: menu File → Export…, file type BibTeX (*.bib).

From EndNote

EndNote does not have a ".bib" option, but its BibTeX Export output style produces exactly that.

  1. Select your references (or a group containing them).
  2. Menu File → Export….
  3. File type: Text File. Output style: BibTeX Export — if it is not in the list, choose Select Another Style… and look for it there.
  4. Name the file with the .bib extension, e.g. endnote.bib, and click Save. If EndNote adds .txt, simply rename the file to end in .bib.

From ORCID, HAL or other sources

  • ORCID — the Works section of your ORCID record can be exported as BibTeX. Your ORCID is usually less complete than Google Scholar, unless you maintain it carefully.
  • Publishers, Web of Science, Scopus, PubMed — all offer a BibTeX export ("Cite" or "Export" button). You can combine several files: open them in a text editor and paste them one after the other into a single .bib file. bib2hal detects duplicates.
  • By hand — a .bib file is plain text. One entry looks like: 
    @article{muller2024,
  title   = {Title of the paper},
  author  = {Muller, Sandrine and Doe, Jane},
  journal = {NeuroImage},
  year    = {2024},
  doi     = {10.1016/j.neuroimage.2024.000000}
}

Then
