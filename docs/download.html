First launch

bib2hal is not yet signed by Microsoft or Apple, so your system asks for confirmation the first time.

Windows

"Windows protected your PC" → click More info → Run anyway.

macOS

Unzip the file. "Cannot be opened because the developer cannot be verified": right-click the file → Open → Open. Only needed once.

Linux

Unzip, then run ./bib2hal-linux-x64 from a terminal (or make it executable and double-click it).

A small window stays open while bib2hal runs — closing it stops bib2hal. Your files are kept in Documents/bib2hal. Then follow the guide.

For Python users

If you have Python 3.9 or later, you can also install it as a command:

pip install git+https://github.com/AI4Health-DAISY-LIG/bib2hal.git
bib2hal ui

Optional: pip install keyring for "Remember me" on every system.
