Data protection

Your data stays with you

bib2hal is a program that runs on your own computer. There is no bib2hal server and no account: the authors of the tool never receive your data.

What is stored, and where

DataWhereWho can see it
Your settings (name, IdHAL, lab, disciplines).env file in your bib2hal folder (Documents/bib2hal)You
Your publication list and review (.bib, review.csv, backups)Your bib2hal folderYou
History of what was submitted (deposit_log.csv)Your bib2hal folderYou
Your HAL login and passwordIn memory while bib2hal runs, or — only if you tick Remember me — in your operating system's keychain (Windows Credential Manager, macOS Keychain, Linux Secret Service). Never in a file.You
The list of HAL disciplines (public)A cache in your user folder (.bib2hal)—

To delete everything: sign out in bib2hal (this also removes the keychain entry), then delete your bib2hal folder.

What leaves your computer

bib2hal connects only to the public services needed for the job, and only when you ask it to:

ServiceWhenWhat is sent
Crossref (api.crossref.org)ImportTitle, first author and DOI of each reference, to find its complete metadata. Optionally, the contact e-mail you enter in Settings (Crossref recommends it).
HAL search & referential APIs (api.archives-ouvertes.fr)Import, settingsTitles and DOIs (to check what is already in HAL), the words you type to search for a lab or a discipline.
HAL deposit API (SWORD)Sign-in, Check, SubmitYour HAL login and password (over HTTPS, as HAL requires), and the records you choose to check or submit.

No analytics, no tracking, no advertising, no data sent to the authors of bib2hal or to any other party. Each of these services applies its own privacy policy to the requests it receives.

The interface in your browser

  • The interface is served by bib2hal itself, on your computer only (127.0.0.1): it cannot be reached from the network.
  • Each session uses a random code, so other websites open in your browser cannot control bib2hal.
  • Fonts and images are included in the application: the page loads nothing from third-party servers.

GDPR

Because bib2hal runs on your computer and its authors receive no data, using it does not involve any processing of personal data by the authors of the tool. The information you submit to HAL is then processed by HAL (CCSD) under HAL's own terms and privacy policy, exactly as if you had used HAL's website.

This documentation website is hosted by GitHub Pages; GitHub records technical information (such as IP addresses) as described in its privacy statement. The download page asks GitHub's public API for the list of releases.
